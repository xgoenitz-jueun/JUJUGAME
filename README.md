# Q版娃娃橫向捲軸打怪遊戲

本專案依 `docs/` 中的五份設計文件建置，為粉絲自製非營利作品，僅供同好交流。

## 目前進度

六關主體、變身、全屏閃電、圖鑑與結局動畫已完成驗收。變身外型採用白蝴蝶結白裙娃娃；第六關 Boss 沿用既有棒球形態／惡魔形態圖片。

## 免費遊玩

GitHub Pages 網址：`https://xgoenitz-jueun.github.io/JUJUGAME/`。每次推送到 `main`，`.github/workflows/deploy.yml` 會自動測試、建置並部署；建置時使用 `/JUJUGAME/` 作為 Vite 基底路徑。

此網址供粉絲圈免費遊玩；不涉及 App 商店上架或商業販售。

## 本機執行

需要 Node.js 20.19+ 或 22.12+。

```bash
npm install
npm run dev
```

手機可直接打開上方 GitHub Pages 網址。若有電腦，本機區網除錯可執行：

```bash
npm run dev:mobile
```

指令固定綁定所有網路介面的 **5173 埠**（若被占用會直接報錯），並在 Network 網址下方列出對應的終端機 QR code。手機與電腦連到同一 Wi-Fi 後，掃描電腦所屬區網 IP 的 QR code；若出現多組網址，選擇與手機同網段的一組。掃描不到時，請檢查防火牆是否允許電腦的 5173 埠連入。

檢查建置：

```bash
npm run build
```

自動化輸入事件與資料邏輯檢查：

```bash
npm test
```

此測試以合成指標事件驗證按鍵、搖桿和 CSS 事件規則，不含真實瀏覽器的像素命中檢查；請以手機試玩確認手感與點擊範圍。

在執行指令的電腦也可開啟 `http://localhost:5173/`。頁面使用 `width=device-width`、`viewport-fit=cover`、`100dvh` 和安全區間距；實際手機手感仍請以裝置確認。

## Phase 1 操作

| 動作 | 鍵盤 | 手機觸控 |
|---|---|---|
| 四向移動、縱深走位 | WASD 或方向鍵 | 左下區域按下後拖曳浮動搖桿 |
| 普通拳拳踢三段連擊 | 快速點按 J | 點按「攻擊」 |
| 粉紅氣功 | 長按 J 或 G，放開發射 | 長按「攻擊」或「氣功」，放開發射 |
| 跳躍／翻滾／蹲下 | K／L／按住 C | 對應獨立按鈕 |

靠近怪物且位於相近縱深可用拳腳命中。按住氣功時能量球逐漸變大，放開瞬間發射粉紅光束。翻滾期間短暫無敵，蹲下可避開遠程投射物。HP 歸零時由最近啟動的傳送點復活；MP 緩慢自動回復。

六關依序推進；擊敗 Boss 後主角升至 Lv4、Lv6、Lv8、Lv9、Lv10。第四關舊存檔會銜接第五關；擊敗第五關巨大紅龍會永久解鎖隱藏第六關並自動進入。選單可重玩已解鎖的第五／六關。怪物掉落金錢與技能點；進度、金錢、裝備、點數及傳送點保存在同一瀏覽器的 localStorage。

藍色風暴：打擊敵人填滿獨立量表後按「風暴」（鍵盤 B）。全屏閃電：打擊敵人填滿另一條獨立量表後按「閃電」（鍵盤 V），藍／金兩色交錯閃爍，攻擊目前整個畫面中的敵人，不消耗 MP。變身：填滿變身量表後按「變身」（T），20 秒內切換外型與數值，結束後冷卻 60 秒。變身期間按「五色」（F）、「防禦」（H）、「流星」（M）。三條獨立量表顯示在左上角。第五關混合怪有獨立關卡數值倍率，紅龍可噴火、尾掃與預警俯衝。第六關含五色飛龍；終極 Boss 第一形態揮棒與丟球，血量降至 20% 轉惡魔形態，生命上限及當前生命重設為原始值的兩倍；第二形態每 50 秒預警 1.8 秒後施放黑紫火焰，傷害為玩家生命上限 30%，可用翻滾無敵幀或變身絕對防禦反制。

五色效果已確認的預設值見 `data/progression/five-color-status.json`：紅燒傷 4 秒，每秒 6 傷害；藍冰凍 1.4 秒，無法移動和攻擊；黃麻痺 2 秒，移動速度減半、無法攻擊；綠中毒 5 秒，每秒 4 傷害；紫暈眩 1.2 秒，無法移動和攻擊，打斷蓄勢中的怪物攻擊。同色再次命中更新持續時間，持續傷害不重複疊加。

`src/config/prototype.ts` 與新增的關卡／怪物／商店 JSON 內的數值是測試手感用的暫定值；規格文件未定案的戰鬥數值不視為正式設定。第一關升至 Lv4 已由使用者確認。

## 目錄

- `src/entities`：角色、怪物與 Boss。
- `src/systems`：戰鬥、經濟、點數與存檔。
- `src/ui`：操作按鈕與介面。
- `src/scenes`：場景載入邏輯。
- `src/state`：角色及變身狀態機。
- `data/enemies`、`data/levels`、`data/shop`、`data/progression`：資料驅動設定。
- `assets/sprites`、`assets/backgrounds`、`assets/audio`：素材預留目錄。

五份原始規格置於 `docs/`；變身外型、五色附加效果與結局文字已按驗收結果實作。
