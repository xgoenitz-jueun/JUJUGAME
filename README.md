# Q版娃娃橫向捲軸打怪遊戲

本專案依 `00_README_使用說明.md`、`01_GDD_核心遊戲設計.md`、`02_關卡與怪物設計.md`、`03_技術架構與GitHub整合.md`、`04_分階段執行與授權計畫.md` 建置，並依 04 文件的 Phase 0→6 順序推進。

## 目前進度

Phase 0：Phaser 3 + TypeScript 骨架完成。Phase 1：核心操作與戰鬥原型完成，使用程式繪製的佔位角色和練習標靶。練習標靶沒有敵人 AI，倒下後兩秒重置；正式怪物、關卡與經濟系統依計畫從 Phase 2 開始。四個資料目錄的 JSON 檔仍是有效但未填入正式設定的骨架。

## 本機執行

需要 Node.js 20.19+ 或 22.12+。

```bash
npm install
npm run dev
```

檢查建置：

```bash
npm run build
```

## Phase 1 操作

| 動作 | 鍵盤 | 手機觸控 |
|---|---|---|
| 四向移動、縱深走位 | WASD 或方向鍵 | 左下區域按下後拖曳浮動搖桿 |
| 普通拳拳踢三段連擊 | 快速點按 J | 點按「攻擊」 |
| 粉紅氣功 | 長按 J 或 G，放開發射 | 長按「攻擊」或「氣功」，放開發射 |
| 跳躍／翻滾／蹲下 | K／L／按住 C | 對應獨立按鈕 |

角色移到標靶附近且位於相近的縱深可用拳腳命中。氣功發射後沿面向飛行，球體隨飛行放大。翻滾期間角色處於短暫無敵狀態；Phase 2 有敵人攻擊時才會實際觸發受擊判定。此階段 HP 是完整的紅色示意條，MP 施放氣功時消耗並逐漸自動回復。

`src/config/prototype.ts` 的數值是為了測試手感設定的暫定值，規格文件未定案的戰鬥數值不視為正式設定。

## 目錄

- `src/entities`：角色、怪物與 Boss。
- `src/systems`：戰鬥、經濟、點數與存檔。
- `src/ui`：操作按鈕與介面。
- `src/scenes`：場景載入邏輯。
- `src/state`：角色及變身狀態機。
- `data/enemies`、`data/levels`、`data/shop`、`data/progression`：資料驅動設定。
- `assets/sprites`、`assets/backgrounds`、`assets/audio`：素材預留目錄。

五份原始規格置於 `docs/`。正式美術尚未套用。公開部署與涉及商標的結局文字依 04 文件對應 ⛔ 節點確認。
