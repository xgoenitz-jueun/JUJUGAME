本專案依 `00_README_使用說明.md`、`01_GDD_核心遊戲設計.md`、`02_關卡與怪物設計.md`、`03_技術架構與GitHub整合.md`、`04_分階段執行與授權計畫.md` 建置，並依 04 文件的 Phase 0→6 順序推進。

## 目前進度

Phase 0–2 已完成，前兩關主角及怪物採用已驗收圖片。Phase 3 試玩版已接入藍色風暴、變身及第三／四關。變身最終外型採用白蝴蝶結白裙娃娃。五色魔法依序施放紅、藍、黃、綠、紫色；命中怪物時造成傷害並附加對應異常狀態。

## 手機試玩預覽

GitHub Pages 預覽網址：`https://xgoenitz-jueun.github.io/JUJUGAME/`。啟用 GitHub Pages 並將來源設為 **GitHub Actions** 後，每次推送到 `main`，`.github/workflows/deploy.yml` 會自動測試、建置並部署；也可從 Actions 手動重新執行。建置時使用 `/JUJUGAME/` 作為 Vite 基底路徑，確保手機瀏覽器可以載入 CSS 與 JavaScript。

此網址供手機試玩，公開網址仍可能被其他人存取；正式發布及上架依 04 文件 Phase 6 另行決定。GitHub 免費方案若使用私人倉庫，必須先將倉庫改成公開才能啟用 Pages，此操作會公開整個倉庫的原始碼與文件。

## 本機執行

需要 Node.js 20.19+ 或 22.12+。

```bash
npm install
npm run dev
```

手機可直接打開上方 GitHub Pages 網址。若有電腦，本機區網除錯可執行：

```bash
npm run dev:mobile
```

指令固定綁定所有網路介面的 **5173 埠**（若被占用會直接報錯），並在 Network 網址下方列出對應的終端機 QR code。手機與電腦連到同一 Wi-Fi 後，掃描電腦所屬區網 IP 的 QR code；若出現多組網址，選擇與手機同網段的一組。掃描不到時，請檢查防火牆是否允許電腦的 5173 埠連入。

檢查建置：

```bash
npm run build
```

自動化輸入事件與資料邏輯檢查：

```bash
npm test
```

此測試以合成指標事件驗證按鍵、搖桿和 CSS 事件規則，不含真實瀏覽器的像素命中檢查；請以手機試玩確認手感與點擊範圍。

在執行指令的電腦也可開啟 `http://localhost:5173/`。頁面使用 `width=device-width`、`viewport-fit=cover`、`100dvh` 和安全區間距；實際手機手感仍請以裝置確認。這個 Pages 網址已由使用者授權作測試預覽；正式發表仍依 Phase 6 另外決定。

## Phase 1 操作

| 動作 | 鍵盤 | 手機觸控 |
|---|---|---|
| 四向移動、縱深走位 | WASD 或方向鍵 | 左下區域按下後拖曳浮動搖桿 |
| 普通拳拳踢三段連擊 | 快速點按 J | 點按「攻擊」 |
| 粉紅氣功 | 長按 J 或 G，放開發射 | 長按「攻擊」或「氣功」，放開發射 |
| 跳躍／翻滾／蹲下 | K／L／按住 C | 對應獨立按鈕 |

靠近怪物且位於相近縱深可用拳腳命中。按住氣功時能量球逐漸變大，放開瞬間發射粉紅光束。翻滾期間短暫無敵，蹲下可避開遠程投射物。HP 歸零時由最近啟動的傳送點復活；MP 緩慢自動回復。

第一關草原、第二關森林、第三關墓地、第四關蠻荒營地依序推進；擊敗 Boss 後升至 Lv4、Lv6、Lv8、Lv9，第四關結束停在 Phase 3 測試終點。若 Phase 2 已擊敗小老虎，原有存檔會銜接第三關。怪物掉落金錢與技能點；角落選單包含四檔補給、四關裝備、背包與配點。進度、金錢、裝備、點數及傳送點保存在同一瀏覽器的 localStorage。

藍色風暴：打擊敵人填滿獨立量表後按「風暴」（鍵盤 B），四張圖同時向前、後、左、右擴散。變身：填滿另一量表後按「變身」（T），20 秒內切換外型、HP／MP 上限按目前比例加倍、力量／防禦／魔力／速度／體力效果加倍；結束後冷卻 60 秒才可重新蓄量表。變身期間按「五色」（F）循環五色魔法、按「防禦」（H）暫時免疫傷害、按「流星」（M）施放一次畫面範圍流星雨。兩條量表與倒數顯示在畫面左上；各技能耗費 MP，流星雨每次變身限一次。

五色效果預設值見 `data/progression/five-color-status.json`，可在驗收後調整：紅燒傷 4 秒，每秒 6 傷害；藍冰凍 1.4 秒，無法移動和攻擊；黃麻痺 2 秒，移動速度減半、無法攻擊；綠中毒 5 秒，每秒 4 傷害；紫暈眩 1.2 秒，無法移動和攻擊，打斷蓄勢中的怪物攻擊。同色再次命中更新持續時間，持續傷害不重複疊加。怪物頭頂顯示狀態名稱，燒傷火星、冰凍冰環、麻痺閃電、毒綠色氣泡、暈眩旋轉光點為場內提示；怪物死亡仍按原有方式掉落獎勵。

`src/config/prototype.ts` 與新增的關卡／怪物／商店 JSON 內的數值是測試手感用的暫定值；規格文件未定案的戰鬥數值不視為正式設定。第一關升至 Lv4 已由使用者確認。

## 目錄

- `src/entities`：角色、怪物與 Boss。
- `src/systems`：戰鬥、經濟、點數與存檔。
- `src/ui`：操作按鈕與介面。
- `src/scenes`：場景載入邏輯。
- `src/state`：角色及變身狀態機。
- `data/enemies`、`data/levels`、`data/shop`、`data/progression`：資料驅動設定。
- `assets/sprites`、`assets/backgrounds`、`assets/audio`：素材預留目錄。

五份原始規格置於 `docs/`。Phase 3 變身外型與五色附加效果已於本次確認；涉及商標的結局文字留待 04 文件 Phase 5 節點。
