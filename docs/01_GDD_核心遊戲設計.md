# 01｜核心遊戲設計文件（GDD）

## 1. 遊戲類型定位
2.5D 橫向捲軸清版動作遊戲（Side-scrolling Beat-'em-up），Q版娃娃主角，手機直式/橫式皆需考慮觸控操作。角色可在畫面內的「深度軸」小範圍上下移動（類似《雙截龍》《怒之鐵拳》的縱深走位），並隨關卡向右（或依關卡設計向左）持續捲動推進。

## 2. 角色基本操作

| 動作 | 說明 |
|---|---|
| 左 / 右移動 | 沿捲軸方向前進後退 |
| 上 / 下移動 | 畫面內縱深走位（用於閃避、繞後、站位） |
| 跳躍 | 單次跳躍，可攻擊出招（空中攻擊可選配） |
| 翻滾 Roll | 短距離位移＋短暫無敵幀（i-frame），用於閃避攻擊 |
| 蹲下 Crouch | 降低受擊判定、可觸發下段攻擊或閃避低位攻擊 |

**輸入建議**：搖桿控制移動＋方向鍵四向映射（上下左右都要能單獨判定），跳躍/翻滾/蹲下各自獨立按鍵，避免和攻擊鍵複合過於複雜（新手友善）。

## 3. 戰鬥系統

### 3.1 普通拳腳攻擊
- 連段設計：至少 3 段連擊（拳、拳、踢），可加入蹲下攻擊、跳躍攻擊變化。
- 消耗：無 MP 消耗，主要清怪與集氣手段。

### 3.2 集氣氣功（粉紅色）
- **蓄力階段**：按住攻擊鍵時，手心先浮現粉紅色氣功雛形（小球狀能量逐漸凝聚、發光強度隨蓄力時間提升）。
- **發射階段**：放開後氣功彈射出，飛行途中球體持續變大（視覺上像滾雪球式膨脹），命中造成範圍略大於普通攻擊的傷害。
- **消耗**：MP。
- **威力定位**：中階遠程技，傷害 > 普攻，< 藍色風暴。

### 3.3 必殺技：藍色風暴（範圍技）
- 以角色為中心向四面八方擴散的藍色風暴波，覆蓋角色周圍一定半徑內所有敵人。
- **威力定位**：> 氣功，屬於清場/救急技。
- **消耗**：較高 MP，或搭配專屬「必殺技量表」（打怪 / 受擊時累積），避免單純用 MP 導致連續施放過強。

### 3.4 超級必殺技：全屏閃電
- 畫面全螢幕閃電特效，**藍色與金黃色交錯切換**（視覺上建議兩色以 0.1–0.2 秒頻率互相閃爍疊加，強化「最強技」的壓迫感）。
- **威力定位**：全遊戲最高單體/群體傷害技，通常配合 Boss 戰或殘局清怪使用。
- **消耗**：滿量的必殺技量表（不建議純 MP，而是獨立「大招槽」，透過戰鬥累積，避免用錢或藥水無限刷）。
- **限制建議**：每場戰鬥有冷卻或量表歸零機制，避免變成無腦解法。

### 3.5 技能強度關係（由弱到強）
```
普通拳腳 < 集氣氣功（粉紅） < 藍色風暴（範圍必殺） < 全屏閃電（超級必殺）
```

## 4. 變身系統

| 項目 | 內容 |
|---|---|
| 觸發方式 | 專屬變身量表集滿後手動觸發（建議來源：普攻/技能命中、吃特定道具、受擊反饋皆可貢獻量表） |
| 外型 | 變成另一款 Q 版娃娃造型（待補參考圖） |
| 數值加成 | 變身後全數值（力量／防禦／魔力／速度／體力）× 2（相對原始角色基礎值） |
| 專屬技能 | 1. **五色魔法**（多屬性攻擊技，可設計為五種顏色對應不同附加效果，如燒傷/冰凍/麻痺/中毒/暈眩，任一顏色隨機或依連段切換）<br>2. **絕對防禦**（短時間內大幅減傷或無敵，用於防守/生存）<br>3. **全屏必殺技：流星雨**（變身狀態下的終極清場技，範圍蓋滿全螢幕） |
| 持續時間 | 20 秒 |
| 冷卻時間 | 60 秒（從變身結束時開始計算，或從觸發時開始計算，建議註明是「觸發後 60 秒可再次集滿」還是「結束後才開始倒數」，實作時二選一並在 UI 上顯示冷卻圈） |
| UI 提示 | 變身中角色外觀變化＋專屬變身特效光環；倒數 20 秒以量表或計時圈顯示，避免玩家不知道還剩多少時間 |

## 5. 血量與魔力條

| 條 | 顏色 | 說明 |
|---|---|---|
| HP | 紅色 | 歸零即死亡，觸發傳送點復活流程（見文件 02） |
| MP | 藍色 | 用於集氣氣功／必殺技消耗；**關卡中會隨時間緩慢自動回復** |

大招槽（藍色風暴／全屏閃電／變身量表）建議獨立於 MP 條之外顯示，避免玩家混淆「打怪用的魔力」跟「大招專用量表」。

## 6. 觸控 UI：半透明懸浮按鈕

- 所有操作按鈕（方向搖桿、跳躍、攻擊、翻滾、蹲下、氣功、必殺技、變身）採**半透明懸浮浮層**，建議透明度 40%–55%，按下時短暫提高不透明度作為回饋。
- 按鈕群集中在畫面左右下方（左：移動搖桿；右：動作按鍵群，参考格鬥/清版手遊常見配置），避免遮擋畫面中央的角色與怪物視野。
- 需考慮手機安全區域（瀏海/圓角），按鈕與畫面邊緣保留安全內距。
- 提供「按鈕透明度」與「按鈕位置」的玩家自訂選項（進階但建議加入，提升手感）。

## 7. 經濟系統

- 打擊怪物掉落**金錢**，用於購買補血食物 / 血瓶。
- **商店**：販售補血食物與血瓶，**補血量與價格成正比**（越貴補得越多），建議至少 3–4 個價位檔次（小/中/大/滿血）。
- **裝備店**：販售可強化自身強度的裝備（武器/防具/飾品皆可），**每進入一個新關卡就會補上新裝備**（確保裝備隨關卡強度成長）。
- 商店、裝備店、技能點數配點，**整合為同一個可收合的選單區塊**（例如畫面角落一個按鈕點開「背包/商店」面板），避免介面雜亂常駐佔用畫面。

## 8. 背包系統

- **物品背包**：消耗品（食物、血瓶、任務道具等）。
- **裝備背包**：可穿戴裝備，需有欄位區分（武器/防具/飾品等，依實作彈性決定分類數）。

## 9. 等級與技能點系統

### 9.1 角色等級（Lv）
- 第一關開始 **Lv3**，隨關卡推進至第五關結束為 **Lv10**。
- 建議設計為「過關里程碑升級」而非傳統打怪吃經驗值升級，確保節奏可控：

| 關卡進度 | 等級 |
|---|---|
| 進入第一關 | Lv3 |
| 通過第一關 Boss | Lv4~5 |
| 通過第二關 Boss | Lv6 |
| 通過第三關 Boss | Lv7~8 |
| 通過第四關 Boss | Lv9 |
| 通過第五關 Boss | Lv10（滿級） |

### 9.2 技能點數（強化素質用）
- 打怪贈與技能點數，**點數分散掉落在各關卡怪物身上**，隨關卡新增可獲得的點數池。
- **總量上限 50 點**，超過 50 點後怪物不再掉落額外可用點數（或掉落但無法再分配，視實作選擇其一，建議直接「滿了就不再掉」較乾淨）。
- 可分配的五項素質：

| 素質 | 影響 |
|---|---|
| 力量 STR | 普攻／物理技傷害 |
| 防禦 DEF | 減免受到的傷害 |
| 魔力 MAGIC | 氣功／必殺技／變身技傷害、可能影響 MP 上限 |
| 速度 SPD | 移動速度、攻速、翻滾距離/頻率 |
| 體力 VIT | HP 上限（可選：影響翻滾/衝刺的體力消耗上限） |

- 技能點數配點介面與商店、裝備店同區塊收合選單呈現。

## 10. 新手教學建議（Onboarding）

建議採「情境式教學」而非一次跳出大量文字：

1. **移動教學**：進入第一關前幾步，彈出上下左右移動提示。
2. **攻擊教學**：遇到第一隻史萊姆時，提示普通攻擊按鍵。
3. **氣功教學**：清掉 2–3 隻史萊姆後，提示「按住攻擊鍵蓄力可發射氣功」，並用一隻稍硬的小怪讓玩家練習。
4. **翻滾/蹲下教學**：遇到會遠程攻擊的敵人時，提示翻滾閃避。
5. **必殺技教學**：接近第一關 Boss 前，提示「藍色風暴」用法（量表滿了會發光提示）。
6. **變身教學**：安排在第一關 Boss 戰或第二關初，當變身量表首次集滿時強制彈出教學提示「變身量表已滿，點擊變身！」。
7. **傳送點教學**：第一次抵達傳送點時彈出提示「這是重生點，陣亡後會從這裡復活」。
8. **商店/裝備教學**：第一次獲得金錢/裝備掉落時，提示點開收合選單查看。

教學提示建議用「半透明對話框 + 對應按鈕高亮」呈現，且只出現一次（有「已完成教學」的旗標記錄，避免重複打擾）。
