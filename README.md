## 本機執行

需要 Node.js 20.19+ 或 22.12+。

```bash
npm install
npm run dev
```

手機實測請在自己的電腦執行：

```bash
npm run dev:mobile
```

指令固定綁定所有網路介面的 **5173 埠**（若被占用會直接報錯），並在 Network 網址下方列出對應的終端機 QR code。手機與電腦連到同一 Wi-Fi 後，掃描電腦所屬區網 IP 的 QR code；若出現多組網址，選擇與手機同網段的一組。掃描不到時，請檢查防火牆是否允許電腦的 5173 埠連入。

檢查建置：

```bash
npm run build
```

自動化輸入事件與資料邏輯檢查：

```bash
npm test
```

此測試以合成指標事件驗證按鍵、搖桿和 CSS 事件規則，不含真實瀏覽器的像素命中檢查；請以手機試玩確認手感與點擊範圍。

在執行指令的電腦也可開啟 `http://localhost:5173/`。本執行環境的容器不在你的 Wi-Fi 網段，這裡顯示的區網網址無法直接由你的手機連線。頁面使用 `width=device-width`、`viewport-fit=cover`、`100dvh` 和安全區間距，避免瀏覽器網址列伸縮或手機邊緣遮住操控區；實際手機顯示仍請以你的裝置確認。公開部署屬 04 文件 Phase 6 的人工確認節點。

## Phase 1 操作

| 動作 | 鍵盤 | 手機觸控 |
|---|---|---|
| 四向移動、縱深走位 | WASD 或方向鍵 | 左下區域按下後拖曳浮動搖桿 |
| 普通拳拳踢三段連擊 | 快速點按 J | 點按「攻擊」 |
| 粉紅氣功 | 長按 J 或 G，放開發射 | 長按「攻擊」或「氣功」，放開發射 |
| 跳躍／翻滾／蹲下 | K／L／按住 C | 對應獨立按鈕 |

靠近怪物且位於相近的縱深可用拳腳命中。氣功發射後沿面向飛行，球體隨飛行放大。翻滾期間短暫無敵，蹲下可避開此原型的遠程投射物。HP 歸零時由最近啟動的傳送點復活；MP 施放氣功時消耗並逐漸自動回復。

第一關是草原，擊敗哥布林後升至 Lv4 並進入第二關森林；擊敗小老虎後升至 Lv6，目前停在 Phase 2 結束畫面。怪物倒下後可拾取金錢與技能點。畫面角落「背包／商店」可打開同一面板購買四檔補給、裝備初階／森林裝備、使用物品和分配五項素質。進度、金錢、裝備、點數及傳送點保存在該瀏覽器的 localStorage。

`src/config/prototype.ts` 與新增的關卡／怪物／商店 JSON 內的數值是測試手感用的暫定值；規格文件未定案的戰鬥數值不視為正式設定。第一關升至 Lv4 已由使用者確認。

## 目錄

- `src/entities`：角色、怪物與 Boss。
- `src/systems`：戰鬥、經濟、點數與存檔。
- `src/ui`：操作按鈕與介面。
- `src/scenes`：場景載入邏輯。
- `src/state`：角色及變身狀態機。
- `data/enemies`、`data/levels`、`data/shop`、`data/progression`：資料驅動設定。
- `assets/sprites`、`assets/backgrounds`、`assets/audio`：素材預留目錄。

五份原始規格置於 `docs/`。正式美術尚未套用；公開部署與涉及商標的結局文字依 04 文件對應 ⛔ 節點確認。
